# Sayuj Krishna — Developer Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio sections and content
- `style.css` — responsive design and styling
- `script.js` — mobile navigation and footer year

## Preview locally
Open `index.html` in a browser. Internet access is needed for hosted images and Google Fonts.

## Publish as a standalone site
Create a repository named `sayuj-portfolio`, upload the files to its root, and enable GitHub Pages in Settings → Pages.

## Personalisation
Update the contact email and replace generic project links with specific repository/demo URLs before sharing widely.
